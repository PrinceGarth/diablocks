# Diablocks: Pixel Dungeon Edition

A tiny Diablo-style hack-and-slash in a voxel dungeon, re-skinned with Pixel Dungeon art.

- **Play in the browser:** https://PrinceGarth.github.io/diablocks/
- `classic.html` is the original Minecraft-style version (no external art).
- `luanti/` is the same game as a real [Luanti](https://www.luanti.org) game: run `luanti/play.sh`. See `luanti/README.md`.

Controls: WASD move, mouse aims, 1/2/3 or wheel swap sword/pickaxe/barricades, LMB attack or dig,
RMB firebolt or place, Space Psionic Blast, F firebolt at the nearest monster, R Scroll of Upgrade (5 gold).
